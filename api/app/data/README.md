# 公立小学校データ

学校種B1（小学校）、設置区分2（公立）のうち、廃止日なし・廃校区分以外の18,069校を収録。
国立・私立、義務教育学校、特別支援学校は含めません。本校・分校は含みます。
市区町村は学校名の「○市立・○区立・○町立・○村立」から抽出し、それ以外は学校所在地から抽出しています。
都道府県・市区町村・学校名・学校コードを保持した加工データです。
学校一覧の更新時は、同じ条件で再抽出し件数・地域名を確認してください。
